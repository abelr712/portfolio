Contexte

La base de données est au centre du processus décisionnel. Dans les métiers de la donnée, il est essentiel de savoir concevoir une base relationnelle en passant par toutes les étapes : analyse des besoins, modélisation, implémentation, alimentation, validation et documentation.

Source du contexte : Programme national du B.U.T. Science des données — Ministère de l’Enseignement supérieur et de la Recherche (2023).

Ce que j’ai réalisé

Avec mon groupe, nous avons travaillé à partir de données concernant les infrastructures de recharge pour véhicules électriques (IRVE). La première étape a consisté à analyser les données et les règles métier afin de réfléchir à une structure de base cohérente. Nous avons ensuite réalisé la modélisation de la base de données avec un modèle entité-association permettant d’identifier les différentes entités, leurs attributs et les relations qui existent entre elles. À partir de cette modélisation, nous avons construit le schéma relationnel nécessaire à l’implémentation de la base. Enfin, nous avons utilisé SQL et PostgreSQL afin de créer les différentes tables, définir les contraintes et implémenter concrètement la base de données.

Résultats

Nous avons obtenu une base de données relationnelle structurée permettant d’organiser les données IRVE en respectant les relations et contraintes définies lors de la phase de conception. Nous avons ensuite utilisé des requêtes pour vérifier la base et exploiter les informations sur les stations et les points de charge. Le code présenté dans le rapport correspond à plusieurs étapes de cette implémentation et certaines captures n’en montrent qu’une partie.

Ce que j’ai appris

J’ai appris à suivre les principales étapes de conception d’une base de données : comprendre les données, modéliser, construire le schéma relationnel, implémenter, alimenter puis vérifier la base. J’ai également approfondi mon utilisation de SQL et ma compréhension des clés, relations et contraintes d’intégrité d’une base relationnelle.
